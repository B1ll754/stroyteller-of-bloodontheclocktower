使用说明与玩法介绍

这是《血染钟楼：暗流涌动》的线下说书人助手。它将身份配置、夜晚顺序、裁量信息、白天提名和复盘集中在同一页面；游戏中的公开发言、私下交流和实际唤醒仍由说书人主持。

玩法介绍：暗流涌动怎么玩

《暗流涌动》是 5 至 15 名非旅行者玩家参与的阵营推理剧本。善良阵营通过信息、讨论与处决找出小恶魔；邪恶阵营通过伪装、错误信息和夜晚击杀让局势进入两人残局。

善良阵营胜利当前小恶魔死亡，且没有猩红女郎等合法传承使游戏继续。
邪恶阵营胜利场上只剩两名或更少存活玩家，且小恶魔仍存活。
白天核心每名存活玩家每天最多提名一次；每名玩家每天最多被提名一次。最高且不平票的合格候选人会被处决。
死亡玩家不能提名，仍可发言，也可在整局剩余时间中使用一次幽灵票。死亡不会公开身份。

角色能力优先于一般规则。陌客与间谍可在相关核验中按规则呈现为不同阵营或角色；中毒、酒鬼的失效信息则由说书人裁量。

开局：配置人数、身份和隐藏信息
  1. 输入 5 至 15 名玩家人数，依座位修改姓名。可手动为每名玩家选角色，或使用“随机身份”。
  2. 系统按人数校验镇民、外来者、爪牙和恶魔配比；男爵会自动将两名镇民名额转为外来者名额。
  3. 若有酒鬼，为其选择一个不在场的镇民认知身份。若有占卜师，必须选定一名其他善良玩家作为红鲱鱼。
  4. 7 人或以上时，为小恶魔设置三名不在场的善良角色伪装。随后可让玩家轮流使用“抽身份”查看自己的身份。
  5. 确认后点击“开始游戏（进入首夜）”。开局后身份不可通过设置界面任意更改；如需纠正实际主持失误，请使用说书人面板的手动修正功能。
屏幕默认仅供说书人查看。玩家查看身份和夜晚信息时，应由说书人线下单独展示或以手势传递，避免将整个界面展示给玩家。
夜晚：按步骤唤醒、选择与裁量

中央提示卡按官方夜晚顺序给出当前应处理的角色。确认目标前，先在线下让对应玩家完成真实选择；此处用于记录选择、计算合法结果并保留复盘。

  • 首夜：人数达到 7 人时先处理爪牙与恶魔互认；随后依序处理投毒者、间谍和首夜信息角色。
  • 其他夜晚：投毒者、僧侣、间谍、小恶魔、守鸦人、殡葬师、共情者、占卜师和管家等会在对应时机出现。
  • 裁量选项：出现“合法信息结果”时，选择要实际给出的结果。清醒健康的角色只会看到合法真实信息；中毒、酒鬼等失效能力可从失效信息集合中裁量。
  • 特殊身份：间谍可查看完整魔典，包括玩家身份与提示标记；守鸦人仅在夜间死亡时触发；殡葬师仅在当天有人因处决死亡时唤醒。
  • 结束夜晚：所有步骤完成后点击“天亮”。页面转入白天，玩家死亡情况应由说书人在线下公开宣布，但不公开死因。
白天：提名、投票、处决与杀手
  1. 选择提名者与被提名者并开始提名。死亡玩家不能提名，但可以成为被提名者。
  2. 在投票区勾选实际投票者。至少达到存活玩家人数的一半的票数，提名才算成功；死者使用幽灵票后会被自动标记为已用。
  3. 得票必须严格高于当前最高票才能成为处决候选人；与最高票相同会造成平票，当天无人处决，除非后来有人取得更高票。
  4. 点击“结束提名并执行上台玩家”结算处决。贞洁者、圣徒、猩红女郎与胜负会在结算中按规则处理。
  5. 杀手可在白天公开发动一次能力。界面会记录目标，并在陌客、间谍等可能登记变化的场景要求说书人选择本次登记。
说书人工具：角色表、复盘与存档
  • 玩家面板：显示实际角色、认知身份、生死与幽灵票状态，且可进行必要的手动死亡/复活修正。
  • 查看角色表：显示说书人魔典所需的身份与提示状态；间谍只能通过夜晚步骤打开专用魔典。
  • 复盘日志：仅说书人可见，记录夜晚选择、给出的信息、登记裁量、死亡、传承和胜负。可用“复制复盘”导出文本。
  • 存档：当前对局保存在本浏览器的 localStorage。刷新页面会恢复；“新开一局”会清除当前存档并重新初始化。
本助手只覆盖《暗流涌动》的标准非旅行者流程。旅行者、传奇角色、额外剧本角色或实体魔典的特殊提示，请由说书人依据当前剧本官方规则处理。
电脑与手机端操作建议

电脑端适合将夜晚提示、玩家面板和复盘同时展开；平板会将玩家面板与日志并排；手机端会自动改为单列，顶部阶段栏、表单和按钮会分行排列。

手机主持时，建议竖屏使用并在夜晚操作前锁定屏幕方向；较长的玩家列表、复盘和说明均拥有独立滚动区域，不会挤压当前行动卡。

主持教程 · 新手带本流程

这份教程面向第一次或刚开始熟悉《暗流涌动》的说书人。系统负责记录身份、夜晚行动、信息结果、提名投票和胜负；你仍需要在线下叫玩家睁眼/闭眼、传递信息、主持讨论并做符合规则的裁量。

1准备与发身份 2首夜行动 3白天讨论处决 4重复至胜负
开局前：先准备好这几件事
  1. 确认人数、座位和角色袋合法；新手可使用“随机身份（官方配比）”。
  2. 确认酒鬼的认知身份、占卜师的红鲱鱼，以及 7 人以上恶魔的三个伪装角色。
  3. 让玩家围成圈坐好，约定称呼和座位编号；提醒大家死亡后仍可发言，但只能使用一次幽灵票。
  4. 点击“抽身份”时一次只让一名玩家查看自己的身份，其他人不要偷看。
主持原则：你可以帮助弱势阵营，但不要为了让某方获胜而改变规则。中毒、酒鬼和陌客等裁量，应始终从系统列出的合法结果中选择。
首夜：叫人、传信息、记结果
  1. 点击当前夜晚行动卡前，先在线下说“请 X 号玩家睁眼”。
  2. 让玩家完成能力选择；如果是信息角色，先在系统中选定要展示的合法结果，再向玩家展示数字、角色或玩家指向。
  3. 说“请闭眼”，再点击“继续”进入下一步。不要跳过系统步骤，也不要提前告诉玩家不该知道的信息。
  4. 爪牙和恶魔互认、恶魔伪装等首夜信息，按屏幕提示展示后再继续。

夜晚结束：看到“夜晚流程完成”后，确认所有即时触发和死亡都已处理，再点击“天亮”。白天只公开谁死亡，不公开死因、身份和具体夜间信息。

白天：按顺序主持，不要直接跳到计票
1. 宣布天亮宣布昨夜死亡者；没有死亡也要明确说“昨夜无人死亡”。
2. 自由讨论让玩家交换信息、私下交谈，并给不善表达的玩家发言机会。
3. 开放提名玩家公开提名，存活玩家每天最多提名一次、每位玩家每天最多被提名一次。
4. 辩护与投票被提名者发言后，再让所有有资格投票的玩家举手或投票。
5. 宣布结果说明票数、是否超过门槛、是否平票，以及谁上处决台。
6. 白天收尾处理杀手等白天能力，确认殡葬师等后续触发，再进入下一夜。

系统现在会按“宣布天亮 → 自由讨论 → 开放提名 → 处决结果 → 白天收尾”逐段引导。每完成一段，点击当前阶段按钮再继续。

信息与裁量：如何使用“随机推荐”
  • 真实信息：清醒且未中毒时，角色应得到的真实合法结果；如果只有一个真实结果，系统会标注“配置唯一确定”。
  • 失效信息：酒鬼、中毒或其他能力失效时，可以从合法但不一定真实的结果中裁量；这不是随意编造。
  • 登记裁量：间谍、陌客等可能在核验中按另一种角色或阵营登记；系统会说明本次登记的影响。
  • “随机推荐”只是辅助选择，最终由说书人确认。推荐旁边的理由用于提醒你它属于哪一类信息，以及可能影响哪条推理链。
常见注意事项
  • 死亡玩家不能提名，但可以被提名；死亡后仍可能有幽灵票。
  • 投票达到存活玩家人数的一半才过门槛；票数严格高于当前最高票才成为处决候选人，平票无人处决。
  • 处决是否真的造成死亡会影响殡葬师和部分胜负判断；不要把“上处决台”直接当成“已经死亡”。
  • 游戏结束后不要继续执行剩余夜晚步骤；先看页面上的胜负提示并宣布获胜阵营。
  • 出现不确定情况时，先暂停讨论，查角色总览或官方规则，再继续结算。
